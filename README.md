# SE120-projects
This repository should contain 3 projects.

## Project 1: Banking Management System
### Expanded Overview
A console-based application that manages customers, bank accounts, and basic financial transactions. The system should demonstrate how different account types share common behavior while applying their own withdrawal, fee, and interest rules.
### Problem Scenario
A small bank wants a simple internal program that helps clerks create customer accounts, deposit money, withdraw money, and check balances. The program must prevent invalid transactions such as negative deposits, withdrawals above the allowed balance, and duplicate account numbers.

## Project 2: Hospital Appointment System
### Expanded Overview
A console-based system for registering patients, managing doctors, and booking appointments. The project emphasizes inheritance through shared person information and encapsulation of appointment details.
### Problem Scenario
A small clinic needs a basic scheduling program. Reception staff should be able to register patients, add doctors with specialties, and book appointments without assigning two patients to the same doctor at the same date and time.

## Project 3: Student Management System
### Expanded Overview
A console-based application for managing students, courses, enrollments, and grades. The system should show how objects can be linked together to represent students enrolled in multiple courses.
### Problem Scenario
An academic department needs a simple program to store student information, register students in courses, enter grades, and display basic academic summaries such as course lists and average grade.
